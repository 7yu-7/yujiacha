微信小程序 · 实时预览

这是 UniApp 客户端在浏览器中的形态预览（H5 编译产物）。同一套源码可用 HBuilderX 编译为微信小程序与 iOS / Android 原生 App。

5 个底部 Tab（PRD 7 信息架构）
  • 行情：全品种三级浏览 + 搜索 + 涨跌榜
  • 地图：省界比色 + 近一周趋势
  • 关注：个性化订阅 + 异动提醒
  • 日报：全国渔价日报表（T+0）
  • 我的：账户 / 主题 / 导出 / 注销
交互提示
  • 点击底部 Tab 切换页面
  • 点击品种卡片查看详情
  • 点击星标一键关注/取消关注
  • 未登录时可体验访客模式；登录后关注数据云端同步
编译为真机小程序 / App
  • 用 HBuilderX 打开 yujiacha/client
  • 运行 → 运行到小程序模拟器 → 微信开发者工具
  • 或运行到手机模拟器 / 真机（App）
  • 后端地址在 src/utils/config.js 中配置
